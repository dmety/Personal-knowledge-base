# 知识网络使用说明

2026-10-12：新增主题含义与别名、完整目录读取、分类/关系逐项审核。AI 不再通过草稿新路径自动建主题，新主题需单独确认；详见 [AI分类与关系判断.md](AI分类与关系判断.md)。下方原有工具仍兼容，但新组织建议优先使用新增流程。完整备份当前为 v3，兼容 v1/v2。

“我的工作空间”默认收起，展开后可进入知识网络。知识主题是独立目录：点击 ＋ 新建主题，在节点菜单新建子主题、重命名或移动；也可拖入节点中部成为子主题，拖至上下插入线进行同级排序。目录最多五层，支持空主题；同一父主题下名称不可重复，仅可删除没有子主题和关联记录的空主题。

点击主题名称查看整个分支的记录，计数按记录去重并排除归档。编辑记录时从目录多选主题，一条记录可属于多个主题；不选则进入“未分类”。标签保留为独立的检索标记，不自动推断父子关系。

在同一编辑页面添加关系，从目标知识下拉框选择已有记录，选择补充说明、依赖、对比或应用案例，并填写关系依据。关系方向为当前记录 → 目标记录。旧的普通关联仍保留在图中。

关系图支持选择主题（包含子主题）、中心知识、一层或两层关联、状态、标题/标签/主题搜索和缩放。默认排除归档。可点击节点或下方列表查看详情；详情中也可以“查看局部网络”。单图最多 60 条，使用主题或中心知识缩小范围。附件挂在所属记录下，不单独建立节点。

草稿节点和草稿发出的关系用黄色虚线表示“待确认”；绿色节点为已整理。关系依据在图下展示；关系本身不证明因果。若建议修改已有记录，正式关系仍保留原样，直到本人接受建议。

## AI 使用

连接知识库插件后，可以说：“搜索与这条知识相关的已审核记录，建议主题路径及关系，说明依据，提交修改建议。”

四个 MCP 工具保留原名。create_knowledge_draft 和 propose_knowledge_revision 增加可选 topic_paths、relations 字段；relations 包含 target_id、kind、note。kind 可选 supplement、depends_on、contrast、example。search_knowledge 的 filters.topic 可筛选主题及其子主题，结果包含主题和关系。已有插件客户端可能需要重新打开对话或刷新工具声明才能看到新参数。

AI 必须先读取记录核对依据，明确区分资料中的联系与推断。在网站“待审核”比较原主题/关系与建议，接受后生成新版本并留存历史。过期建议不能覆盖原记录。

## 数据兼容与恢复

旧记录读取时自动补齐空 topic_paths 和 relations，无需改写原数据库或清空实例。新增 D1 topic_directories 表保存按用户隔离的目录及修订号，首次读取从已有 topic_paths 补齐父节点，重复迁入不重复创建。记录仍保存 topic_paths；目录重命名或移动会在同一事务中更新关联记录、递增版本并留存历史，旧历史快照保持原路径，过期修改返回 409。

JSON 与完整 ZIP 备份升级为 v2，包含空主题和目录顺序；Markdown 包含记录当时的主题路径。v1 备份仍可导入并从路径建立目录。导入检查循环、缺失父节点、同级重名和缺失主题；同路径合并保留当前目录位置，新节点使用本地 ID，备份中的新节点按原顺序追加。导入预览同时列出重复主题。

先导出备份再做批量整理。独立虚构示例包含少量主题关系，只有点击“导入示例”才使用，已存在的示例 ID 默认跳过。

## 图谱交互（2026-10-10）

图谱采用类似 Obsidian 的力导向交互：节点自动聚拢/排斥，连接更多的节点稍大；拖动节点调整位置，拖动空白平移画布，滚轮在鼠标位置缩放，手机可双指缩放。悬停突出相邻节点和连线；点击节点打开正文，并自动回到详情顶部。支持暂停/继续布局、适应画布、全屏、调整连线长度与排斥力，以及隐藏孤立节点。

这是知识库自己的图谱实现，不是 Obsidian 插件，不包含其全部能力。关系仍以本站记录和审核流程为依据。

独立无界面 Edge 真实浏览器验收通过：1440px 桌面点击/正文/滚动定位、滚轮缩放、空白平移、节点拖动不触发跳转；390×844 手机模拟视口的双指缩放、点击详情、无横向溢出；未出现 JavaScript 页面错误。生成并查看了桌面、手机图谱和手机详情截图。内置浏览器工具仍因环境启动问题不可用，但这次已通过独立浏览器完成视觉与交互验收；未在实体手机上测试。

## 2026-10-13 网络层级与关联补全

默认主题体系使用层级布局，方形为主题、圆形为记录，蓝线为父子层级、细灰线为记录归属。空主题和多主题归属保留；点击主题筛选分支，点击记录打开正文。可切换力导向布局或记录关系视图；详情局部网络默认使用记录关系。

主题横向关联与记录正式关系显示依据。开启“显示推荐虚线”后，显示已接受的弱关联推荐；推荐不等于正式关系。待审核组织建议和修改副本不作为知识节点。单图最多 60 条记录和 100 个主题，超出时提示缩小范围，中心记录优先保留；关系另一端被筛选或截断时显示提示。
