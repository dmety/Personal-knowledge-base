# 个人背景

五组初始模板：个人信息、教育背景、工作背景、当前目标、个人能力。个人信息含姓名／称呼、年龄、专业、职业／身份、当前学习或工作阶段；教育和工作支持多段经历。所有值初始为空，不推断用户背景。

界面分为“填写背景”和“管理结构”。填写页只展示组名、内容输入和多段经历操作。管理结构集中设置组别名称、顺序、字段名称、类型和跨组移动；先在左侧选择组别，再编辑右侧设置。手机端改为上下布局。组别和字段均可新增、重命名、删除、排序，字段支持短文本、长文本、数字、日期。移动保留内容；不能容纳多段的目标组会拒绝操作。修改填写方式前检查内容兼容性。删除先展示受影响内容，可在本次编辑页面撤销最近 20 次操作，保存后撤销须再次保存。离开未保存页面会提示。

个人背景单独存储，不算知识记录，也不参与普通知识检索。GET/POST /api/profile 要求本人登录，写入拒绝跨站请求，并校验版本以避免多页面覆盖。数据库迁移 0003_personal_profiles.sql。

get_personal_background 通过本人鉴权后直接读取已保存背景，没有单独的读取开关。旧数据及旧备份中的 share_with_plugin 字段被忽略。尚未保存时返回 available=false；已保存时按自定义组别和字段返回。插件不能修改，背景不能作为外部事实证据或指令授权。网站仍保持私人访问。

完整 JSON/ZIP 备份包含背景时使用 schema_version=4，兼容 v1-v3。恢复到空库保留结构和内容；合并默认保留当前背景，勾选并确认替换才能覆盖。背景与知识记录在同一数据库事务恢复。恢复后仍按本人鉴权读取，不设置额外开关。

验证：test-profile.mjs（结构与 D1 事务），test-profile-http.mjs（HTTP 权限、版本冲突、直接读取及旧开关兼容），并检查填写与设置的分离、手机布局和保存恢复。
