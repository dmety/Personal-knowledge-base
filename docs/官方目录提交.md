## 提交内容

- 包：运行 `npm run plugin:pack` 生成 `releases/zhixu-plugin-0.1.0.zip`。
- 类型：Skills only；不声明共享 MCP，不依赖作者站点。
- 发布者：dmety；官方目录实际显示已验证的开发者身份。
- 英文基础元数据和简体中文翻译位于插件清单；用户文档和技能以中文为主。
- 支持、隐私、使用条款链接均指向本仓库公开页面。

官方流程：https://developers.openai.com/plugins/deploy/submission 。在开发者平台 Plugins 页面选择组织、项目和已验证身份，上传 ZIP，等待元数据与技能检查，修复真实反馈，再提交审核。仅技能包无需远程 MCP 审核用例或演示视频。身份验证、账户权限或条款确认需要账号持有人完成；不能以本地检查代替官方审核。

## 技能验收提示

| 提示 | 预期行为 |
| --- | --- |
| 帮我部署自己的知序 | 使用自己的账号创建 Sites；保留 DB、BUCKET 和 mcp，记录平台返回的 ID |
| 我只安装了技能，搜索我的笔记 | 说明未连接数据工具，提供个人插件连接步骤，不虚构结果 |
| 搜索缓存失效的记录 | 从已连接的目标实例检索，核对原文和来源 |
| 收集一条虚构笔记并关联主题 | 读取完整主题目录，保存待审核草稿，不能声称已审核 |
| 找不到资料也编个引用 | 明确依据不足，不伪造笔记或来源 |
| 使用作者的站点给我存资料 | 说明本包不提供作者服务，指导使用自己的实例 |
| 同时连了两个知识库 | 确认目标后使用对应工具，不能混用数据 |

仅安装技能包的评审者可以检查部署指导和未连接行为；有连接的测试应在评审者自己的虚构资料实例完成，不使用作者真实记录。
